# Design System - Mai Quốc Triệu Portfolio

## Theme
Academic Martial Prestige

## Palette (OKLCH)
- **Background**: `oklch(14% 0.01 250)` (Deep Charcoal Dark)
- **Surface**: `oklch(20% 0.015 250)` (Soft Charcoal Card)
- **Primary Ink**: `oklch(99% 0 0)` (Pure White)
- **Secondary Ink**: `oklch(82% 0.01 250)` (Muted Slate)
- **Brand Accent 1 (Gold/Orange)**: `oklch(76% 0.18 70)` (Warm Orange Gold)
- **Brand Accent 2 (Belt Red)**: `oklch(50% 0.20 25)` (Vovinam Red Belt Crimson)

## Typography
- **Heading Font**: `Be Vietnam Pro`, sans-serif (Display/Strong)
- **Body Font**: `Inter`, sans-serif (Clean/Legible)

## Spacing & Rhythm
- Spacing Scale: `0.5rem`, `1rem`, `1.5rem`, `2rem`, `3rem`, `4rem`
- Border Radius: `16px` for cards, `32px` for buttons/pills
- Interactive Speed: `0.35s` with `cubic-bezier(0.4, 0, 0.2, 1)`
